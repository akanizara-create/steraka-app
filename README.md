# Steraka — keep yourself in check

A mobile web prototype of **Steraka**, a private streak-accountability app: track habits you're quitting or building, check in daily with photo proof (Time Capsule), lean on accountability partners, and let Steraka Magic (AI) draft streaks for you.

Plain HTML/CSS/JS, no build step. Open `index.html` or deploy as a static site.

## Screens
Onboarding · pattern setup & lock · home feed (Mine / Explore / Discover) · My Streaks carousel · streak stats · Time Capsule · analytics · daily check-in + celebration · "I slipped" (freeze / restart) · custom streak form · Steraka Magic chat & templates · accountability inbox & partners · public streak detail · profile & settings.

Data is stored in `localStorage` (demo data can be reset from Profile). Photos from Unsplash.
